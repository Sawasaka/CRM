# Rookie Smart Japan Logo Set

Company name: 株式会社ルーキースマートジャパン

## Variants

- `rsj-01-wordmark`: Existing service wordmark direction. Best first choice for the current sidebar/header tone.
- `rsj-02-monogram`: App-icon friendly direction with an `R` mark. Good for favicon, account icon, and compact UI.
- `rsj-03-orbit`: Homepage visual direction with a small orbit mark. Good for hero sections and branded cards.
- `rsj-04-apex-signal`: Enterprise SaaS direction with a sharp apex mark. Best recommended enterprise option.
- `rsj-05-grid-core`: Data platform direction with a structured grid mark. Good for company DB and infrastructure messaging.
- `rsj-06-nexus-ring`: Connected CRM direction with a ring/network mark. Good for integration and ecosystem messaging.
- `rsj-07-prism-line`: Sales operating system direction with a prism/growth mark. Good for energetic enterprise visuals.
- `rsj-08-sovereign-wordmark`: Conservative corporate wordmark direction. Good for contracts, documents, and formal contexts.

## Sizes

- `*-logo.svg` / `*-logo.png`: 720 x 180 logo asset.
- `*-home.svg` / `*-home.png`: 1600 x 520 homepage/banner asset.

Use SVG for implementation where possible. Use PNG for quick visual checks, proposals, and no-SVG environments.
