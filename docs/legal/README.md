## 弁護士レビュー時の重点確認項目

### 利用規約

1. **第6条 (クレジット永久有効・解約時失効)** — 資金決済法 (前払式支払手段) との関係
2. **第12条 (損害賠償の上限・責任制限)** — 消費者契約法第8条との整合性 (B2B故合法だが、IT規約として一般的か)
3. **第15条 (規約の一方的変更)** — 民法第548条の4 (定型約款) 対応
4. **第11条 (退会時のクレジット失効)** — 消費者契約法第10条との関係

### プライバシーポリシー

1. 第三国 (米国) への個人情報移転に関する同意取得方式
2. AI事業者への送信データの位置付け (個人情報の第三者提供 or 委託?)
3. 議事録・通話録音などのセンシティブ情報の取扱い
4. 個人情報保護法改正対応 (2022年改正以降の最新版)

### 特定商取引法に基づく表記

1. 個人情報 (代表者所在地・電話番号) の公開範囲
2. クーリング・オフ非適用の根拠 (BtoB限定の明記)

## 2026-05-17 確認メモ

- 外国にある第三者への個人データ提供・個人関連情報提供では、本人同意時の情報提供、相当措置の継続確認、支障時の措置が論点になるため、AI事業者・決済・メール配信等の委託先一覧は公開直前に再確認する。
- 通信販売の申込み画面では、消費者が契約内容を一覧性をもって確認できる表示、誇大広告等の禁止、申込み内容の確認・訂正機会が論点になるため、決済画面と特商法表記を分けずに確認する。
- 規約変更条項は、民法の定型約款変更ルールに合わせて、変更内容・効力発生日・周知方法を明記する。
