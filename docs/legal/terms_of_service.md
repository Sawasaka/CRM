# ルキスマCRM 利用規約 (ドラフト)

> **ステータス**: ドラフト v0.2 (2026-05-04 改定 — 初期費用オプション・データ移行サポート条項追加)
> **最終確認**: 公開前に IT契約に強い弁護士のレビューを必須とする
> **対象**: 法人向けSaaS「ルキスマCRM」(以下「本サービス」)

---

## 第1条 (適用)

1. 本利用規約 (以下「本規約」) は、株式会社ルーキースマート (以下「当社」) が提供するクラウドサービス「ルキスマCRM」(以下「本サービス」) の利用条件を定めるものです。
2. 本サービスの利用契約 (以下「本契約」) は、本サービスの利用を申し込み、当社がこれを承諾した時点で成立するものとします。
3. 本規約は本サービスの利用に関する一切の関係に適用されます。

## 第2条 (定義)

本規約において使用する用語の定義は、以下のとおりです。

| 用語 | 定義 |
|---|---|
| **利用者** | 本サービスを利用する法人、団体または個人事業主 |
| **テナント** | 利用者ごとに割り当てられる本サービス上の独立した利用空間 |
| **管理者** | テナントの代表者として、シート購入・プラン変更・メンバー管理等の権限を有する利用者 |
| **メンバー** | 管理者によって招待された、テナント内で本サービスを利用する自然人 |
| **シート** | 本サービスを利用するメンバー1名分の利用権 |
| **クレジット** | 本サービスのAI機能等の利用量計測単位 |
| **サブスクリプション・クレジット** | 月額プランに付帯して毎月付与されるクレジット |
| **追加購入クレジット** | 利用者が別途購入する追加分のクレジット |
| **AI機能** | 議事録自動取得・BANT自動入力・社内チャット・メール生成等、生成AIを利用する機能の総称 |

## 第5条 (料金および支払方法)

1. 利用者は、当社が別途定める本サービスの料金 (シート料金、追加クレジット料金、有料オプション料金等) を、当社が指定する方法により支払うものとします。
2. 料金は、本サービス内に表示される金額 (税抜) に消費税相当額を加算した金額とします。
3. **月額契約の場合**: 毎月の課金日に、当該月分の料金が決済されます。
4. **年額契約の場合**: 契約日に1年分の料金が一括決済されます。月割換算で表示されている金額はあくまで参考表示です。
5. **シート増減**: 月の途中でシート数を変更した場合、日割計算により次回課金日に調整額が反映されます。
6. **初期費用 (買い切りオプション)**: データ移行サポート等の初期費用オプションは、申込時の **一括決済** とし、**返金は致しません**。役務提供開始後の解約・キャンセルにおいても返金請求権は発生しません。
7. **支払遅延**: 利用者が料金の支払いを遅延した場合、年14.6%の割合による遅延損害金を支払うものとします。
8. **返金**: いかなる場合も、既に支払われた料金 (月額・年額・初期費用・追加クレジット購入を含む) は返金されないものとします。ただし、当社の重大な責めに帰すべき事由により本サービスが提供されなかった場合を除きます。

## 第6条 (クレジット)

1. クレジットは本サービスのAI機能等の利用に必要となる単位であり、各機能の消費レートは当社が別途定めます。
2. **サブスクリプション・クレジット** は、契約プランに応じて毎月付与され、当該月内のみ有効です。**未使用分は翌月へ繰り越されず、月末に失効** します。
3. **追加購入クレジット** は購入時に即時付与され、原則として **有効期限はありません** (永久繰越)。
4. クレジット消費の優先順位は、**サブスクリプション・クレジット → 追加購入クレジット** の順とし、利用者は順序を選択できないものとします。
5. クレジット残高は本サービス内のダッシュボードにて随時確認できます。
6. **クレジットは現金、商品、その他のサービスに交換することはできません**。譲渡、転売、相続もできません。
7. **本契約の終了 (解約・利用停止・サービス終了等を含む) 時点で、未使用のクレジットはすべて失効** し、返金請求権は発生しません。

## 第7条 (シート)

1. 利用者は管理者を通じてシートを購入し、シート数の範囲内でメンバーを招待することができます。
2. **最低契約シート数**: 1シートから利用可能です。Freeプランは最大3シートまでとし、4シート目以降の追加には Standard 以上のプランへの変更が必要です。
3. シートの増設は本サービス上で随時可能です。
4. **シートの減数**: 在籍メンバー数を下回るシート数への減数はできません。シート減数を希望する場合、先にメンバーを削除する必要があります。
5. シート減数は次回課金日から反映され、それまでの差額の返金は行いません。
