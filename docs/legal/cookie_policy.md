# ルキスマCRM Cookie ポリシー (ドラフト)

> **ステータス**: ドラフト v0.1 (2026-05-17 作成)
> **最終確認**: 公開前に弁護士・マーケティング運用責任者のレビュー必須
> **対象**: ルキスマCRM のWebサイトおよびサービス画面

---

株式会社ルーキースマート (以下「当社」) は、当社が提供するWebサイトおよびクラウドサービス「ルキスマCRM」(以下「本サービス」) におけるCookieおよび類似技術の利用について、以下のとおりCookie ポリシー (以下「本ポリシー」) を定めます。

## 第1条 (Cookie 等の利用)

Cookie とは、利用者がWebサイトまたは本サービスを閲覧・利用した際に、ブラウザに保存される小さなテキスト情報です。当社は、ログイン状態の維持、セキュリティ、利用状況分析、サービス改善、広告効果測定等のためにCookieおよび類似技術を利用します。

## 第2条 (Cookie の種類)

| 種類                       | 利用目的                                                   | 無効化した場合の影響                             |
| -------------------------- | ---------------------------------------------------------- | ------------------------------------------------ |
| 必須Cookie                 | ログイン、認証、セッション維持、セキュリティ、不正利用防止 | 本サービスの主要機能が利用できない場合があります |
| 機能Cookie                 | 言語、表示設定、UI状態、入力途中の状態保持                 | 利便性が低下する場合があります                   |
| 分析Cookie                 | アクセス数、利用機能、エラー、導線、パフォーマンスの分析   | サービス改善の精度が下がる場合があります         |
| 広告・マーケティングCookie | 広告配信、効果測定、リターゲティング、キャンペーン分析     | 広告内容の最適化が制限されます                   |

## 第3条 (利用予定の外部サービス)

当社は、以下の外部サービスを利用する場合があります。実際に導入するサービスは、公開前または導入時に最新化します。

| サービス              | 提供者               | 主な目的                   |
| --------------------- | -------------------- | -------------------------- |
| Google Analytics 4    | Google LLC           | アクセス解析・利用状況分析 |
| Google Tag Manager    | Google LLC           | タグ管理                   |
| Google Ads            | Google LLC           | 広告効果測定               |
| Meta Pixel            | Meta Platforms, Inc. | 広告効果測定               |
| Stripe                | Stripe, Inc.         | 決済・不正利用防止         |
| NextAuth / 認証Cookie | 当社・認証基盤       | ログイン状態の維持         |

## 第4条 (Cookie の管理)

利用者は、ブラウザの設定によりCookieを削除または無効化できます。ただし、必須Cookieを無効化した場合、本サービスの一部または全部が正常に動作しない場合があります。

代表的なブラウザの設定方法は、各ブラウザ提供元のヘルプページをご確認ください。

- Google Chrome
- Safari
- Microsoft Edge
- Firefox

## 第5条 (同意管理)

当社が広告・マーケティングCookieその他任意Cookieを利用する場合、必要に応じてCookie同意バナー、設定画面、オプトアウト方法を提供します。

## 第6条 (プライバシーポリシーとの関係)

Cookie等により取得される情報が個人情報または個人関連情報に該当する場合、当社はプライバシーポリシーに従って取り扱います。

## 第7条 (変更)

当社は、利用するCookie、外部サービス、法令または本サービス内容の変更に応じて、本ポリシーを変更することがあります。重要な変更については、本サービス上または当社Webサイト上で通知します。
