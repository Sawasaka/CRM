# ルキスマLAB プライバシーポリシー（ドラフト）

> 最終更新: 2026-07-25
> 運営: 株式会社ルーキースマートジャパン
> 公開前に個人情報保護およびIT契約に詳しい専門家の確認を受けてください。

株式会社ルーキースマートジャパン（以下「当社」）は、「ルキスマLAB」の名称で提供するRevenue Experiment Infrastructure（売上実験インフラ）の企画、データ収集・計測設計、確率シミュレーション、統計分析、実験・配分設計、開発、導入、運用支援、関連するクラウドシステム、AI機能、コンテンツその他一切のサービス（以下「本サービス」）における個人情報および利用者データの取扱いについて、本ポリシーを定めます。

## 第1条（取得する情報）

当社は、本サービスの提供にあたり、次の情報を取得する場合があります。

1. 会社名、部署名、氏名、役職、メールアドレス、電話番号
2. 相談内容、予約日時、商談・ヒアリング内容
3. 契約、発注、請求および支払に関する情報
4. 広告・検索キーワード、アクセス解析、顧客情報、商談情報、受注・売上・継続情報、会議音声、議事録、メール、カレンダー、文書、画像、通話履歴その他利用者が提供または連携する情報
5. Google Analytics、Google Ads、Google Search Console、Google Workspace、Microsoft 365、HubSpot、Salesforce、Slack、BigQueryその他外部サービスの連携情報および認証情報
6. IPアドレス、Cookie、端末・ブラウザ情報、閲覧ページ、参照元、操作履歴、エラー情報等のアクセス情報

当社は、利用者の承諾および必要な権限に基づき、支援に必要な範囲でこれらの情報を取り扱います。

## 第2条（利用目的）

取得した情報は、次の目的で利用します。

1. 相談予約、問い合わせ対応、本人確認および連絡
2. 提案、見積、契約、発注、請求および支払管理
3. 売上実験インフラの企画、設計、開発、導入、運用支援および保守
4. データ整合性の確認、統計分析、確率シミュレーション、実験評価、配分提案およびAIによる処理
5. セキュリティ確保、不正利用防止、障害対応および品質改善
6. 個人または企業を識別できない形に加工した統計情報の作成
7. 新サービスの研究開発
8. 当社サービス、セミナー、コンテンツ等の案内
9. アクセス解析および広告効果測定

法令上必要な場合を除き、案内の停止を希望する利用者には停止手段を提供します。

## 第3条（AI処理）

1. 本サービスのAI機能、分析、要約、検索、生成および自動化では、入力データおよび連携データをOpenAI、Googleその他当社が選定するAI事業者へ送信して処理する場合があります。
2. 当社は、契約、API利用または設定により、送信データがAI事業者の汎用モデル学習に利用されないよう合理的な措置を講じ、利用目的に必要な範囲に限定してデータを処理します。
3. AI処理のため、日本国外のデータセンターまたは外国に所在する事業者へ一時的に送信される場合があります。当社は、委託先の安全管理措置およびデータ利用条件を確認します。
4. AI出力は参考情報です。利用者は、重要な判断または顧客への送信前に、人による確認を行うものとします。

## 第4条（外部サービス・委託）

1. 本サービスでは、Google Analytics、Google Ads、Google Search Console、Google Workspace、Microsoft 365、HubSpot、Salesforce、Slack、BigQuery、AWS、OpenAI、Googleその他の外部サービスを利用または連携する場合があります。
2. 利用するサービスは、支援内容および利用者との合意により異なります。
3. 当社は、クラウド運用、AI処理、メール配信、決済、アクセス解析その他本サービスの提供に必要な業務を外部事業者へ委託する場合があります。
4. 当社は委託先を適切に選定し、契約および必要な監督を行います。
5. 外国に所在する事業者へ個人情報等を提供または処理委託する場合、適用法令に従い、提供先の制度、安全管理措置およびデータ利用条件を確認します。

## 第5条（第三者提供）

当社は、次の場合を除き、個人データを第三者へ提供しません。

1. 本人または利用者の同意がある場合
2. 法令に基づく場合
3. 人の生命、身体または財産の保護に必要で、本人の同意を得ることが困難な場合
4. 公衆衛生の向上または児童の健全な育成に特に必要で、本人の同意を得ることが困難な場合
5. 国または地方公共団体等の法令上の事務に協力する必要がある場合
6. 事業承継に伴う場合
7. 業務委託先へ目的達成に必要な範囲で提供する場合

## 第6条（保管・安全管理）

1. 当社は、取り扱う情報の性質およびリスクに応じ、アクセス制御、認証、通信時・保管時の暗号化、ログ取得、権限管理その他合理的な安全管理措置を講じます。
2. データの保存場所および保存期間は、利用する外部サービス、個別契約および法令上の要請により異なります。
3. 契約または支援終了後の利用者データは、個別契約または利用者との合意に従い、法令上保存が必要な情報を除いて合理的な期間内に削除または返却します。
4. 個人情報または利用者データの漏えい、滅失、毀損等が発生し、またはそのおそれを認識した場合、当社は事実確認、被害拡大防止、必要な報告・通知および再発防止を行います。

## 第7条（Cookie・アクセス解析）

1. 当社Webサイトでは、表示・セキュリティ・利便性の確保、利用状況の分析および広告効果測定のため、Cookieその他の類似技術を利用する場合があります。
2. 利用者はブラウザ設定によりCookieを無効化できますが、一部機能が正常に動作しない場合があります。
3. Cookieおよび分析・広告サービスの詳細は、当社のCookieポリシーに定めます。

## 第8条（本人の権利）

本人は、当社が保有する自己の個人情報について、法令に基づき、利用目的の通知、開示、訂正、追加、削除、利用停止、消去または第三者提供停止を請求できます。当社は本人確認を行ったうえで、法令に従い対応します。
