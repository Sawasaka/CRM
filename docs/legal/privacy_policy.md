# ルキスマCRM プライバシーポリシー (ドラフト)

> **ステータス**: ドラフト v0.2 (2026-05-17 改定 — AI処理・外国事業者委託・Cookie表記を補強)
> **最終確認**: 公開前に弁護士のレビュー必須
> **対象**: クラウドサービス「ルキスマCRM」

---

株式会社ルーキースマート (以下「当社」) は、当社が提供する「ルキスマCRM」(以下「本サービス」) における、個人情報を含むユーザー情報の取扱いについて、以下のとおりプライバシーポリシー (以下「本ポリシー」) を定めます。

## 第1条 (収集する情報)

当社は、本サービスの提供にあたり、以下の情報を取得します。

### 1. 利用登録時に取得する情報

- 会社名・部署名・氏名・役職
- メールアドレス
- 電話番号
- 請求先情報 (法人名、所在地、担当者情報)
- 決済情報 (クレジットカード情報は決済代行会社 Stripe 経由で処理。当社サーバーには保存しません)

### 2. 本サービス利用に伴い取得する情報

- 顧客データ (利用者が登録した企業情報・コンタクト情報・取引情報)
- 議事録・会議録音 (Google Meet 等の連携機能を通じて取得した音声・テキストデータ)
- メール・カレンダーデータ (Gmail / Google Calendar 連携を承諾した場合)
- 通話履歴・録音 (Plivo 経由のワンクリック通話機能を利用した場合)
- 利用ログ (アクセス日時、IPアドレス、ブラウザ情報、利用機能、操作履歴等)

### 3. 第三者サービスから取得する情報

- 国税庁法人番号公表サイト (公開情報)
- gBizINFO API (公開情報)
- その他、利用者の同意を得て連携した外部サービスからの情報

## 第2条 (利用目的)

当社は、取得した情報を以下の目的で利用します。

1. 本サービスの提供・運営・改善のため
2. 利用者からのお問い合わせへの対応のため
3. 利用者に対する重要なお知らせの通知のため
4. 利用料金の請求・回収のため
5. 利用規約違反等への対応のため
6. 統計的データの作成 (個人または企業を特定できない形に処理した上で利用)
7. 新機能・サービスの研究開発のため
8. マーケティング活動 (オプトイン同意がある場合に限る)

## 第3条 (AI機能における情報処理)

1. 本サービスのAI機能 (議事録要約・BANT自動入力・社内チャット・メール生成等) では、利用者が入力したデータおよび連携データを、以下の生成AIサービスに送信して処理します。
   - **OpenAI** (OpenAI API 対応モデル)
   - **Google** (Gemini API 対応モデル)
2. これらのAIサービス事業者との契約において、**送信データはAIモデルの学習には利用されない設定 (オプトアウト) を適用** しています。
3. AIによる出力は参考情報であり、利用者は最終判断を自身の責任で行うものとします。
4. AI機能の利用ログ (送信トークン数、応答時間等) は、サービス改善のため当社にて保存します。
5. AI処理のため、入力データが日本国外のデータセンターまたは外国に所在する事業者に一時的に送信される場合があります。当社は、委託先の安全管理措置、データ利用条件および再委託条件を確認し、必要な範囲で継続的に見直します。

## 第4条 (情報の保管)

1. **保管場所**: 利用者から取得した情報は、AWS東京リージョン (Supabase 経由) に保管されます。原則として日本国外への移転は行いません。
2. **暗号化**: 保管時 (at rest) に AES-256 による暗号化、通信時 (in transit) に TLS 1.3 による暗号化を実施しています。
3. **アクセス制御**: 当社内における情報へのアクセスは、業務上必要な最小限の従業員に限定し、アクセスログを保管しています。
4. **保管期間**:
   - 利用者データ: 本契約存続期間中
   - 退会後: 30日以内に削除 (法令に基づき保管が必要な情報を除く)
   - 利用ログ: 取得から最大2年間
   - 決済関連情報: 法令に基づき7年間

## 第5条 (情報の第三者提供)

1. 当社は、以下の場合を除き、取得した情報を第三者に提供しません。
   - (1) 利用者の同意がある場合
   - (2) 法令に基づく場合
   - (3) 人の生命、身体または財産の保護のために必要がある場合であって、利用者の同意を得ることが困難である場合
   - (4) 業務委託先に本サービス運営のために必要な範囲で提供する場合 (下記第6条)
   - (5) 事業承継に伴う場合

## 第6条 (業務委託先)

当社は、以下の業務を外部の事業者に委託しています。委託先の選定・監督については、当社の責任において適切に行います。

| 委託先                    | 国・地域                            | 委託業務                                  |
| ------------------------- | ----------------------------------- | ----------------------------------------- |
| Amazon Web Services, Inc. | 日本 (東京リージョン)               | データ保管・処理基盤                      |
| Supabase, Inc.            | 米国 (データは日本リージョンに保管) | データベース運用基盤 (AWS東京上に構築)    |
| OpenAI, L.L.C.            | 米国                                | AI機能 (GPT-4o系)                         |
| Google LLC                | 米国                                | AI機能 (Gemini系) / Google Workspace 連携 |
| Plivo Inc.                | 米国                                | 通話機能                                  |
| Stripe, Inc.              | 米国                                | 決済処理                                  |
| Resend Inc.               | 米国                                | メール配信                                |
| Cloudflare, Inc.          | 米国                                | CDN・セキュリティ                         |

**第三国 (外国) への個人情報移転について:**
上記の通り、一部のサービスでは米国の事業者に処理を委託していますが、データ保管自体は AWS東京リージョン上で行われます。AI処理時は一時的に米国を含む海外のデータセンターに送信されますが、各事業者は個人情報保護に関する適切な体制 (SOC 2、ISO 27001 等) を有しています。

## 第7条 (Cookie 等の利用)

本サービスは、利用者の利便性向上のため Cookie を利用しています。Cookie は以下の目的で利用されます。

- ログイン状態の維持
- 利用者の利用状況の分析 (Google Analytics 4 等)
- マーケティング・広告効果測定 (該当する場合)

利用者は、ブラウザの設定により Cookie の受け入れを拒否することができますが、その場合本サービスの一部機能が利用できないことがあります。

Cookie の種類、利用目的、無効化方法の詳細は、当社「Cookie ポリシー」に定めます。

## 第8条 (利用者の権利)

利用者は、自己の個人情報について、以下の権利を有します。

1. **開示請求権**: 当社が保有する自己の個人情報の開示を求める権利
2. **訂正・追加・削除請求権**: 個人情報の内容が事実でない場合に、訂正、追加、削除を求める権利
3. **利用停止・消去請求権**: 個人情報の利用目的を超えて利用されている場合等に、利用停止または消去を求める権利
4. **第三者提供停止請求権**: 第三者への提供の停止を求める権利

これらの権利を行使する場合は、本ポリシー末尾の連絡先までお問い合わせください。

## 第9条 (安全管理措置)

当社は、個人情報の漏洩、滅失または毀損の防止その他の個人情報の安全管理のため、以下の措置を講じています。

1. **組織的安全管理措置**: 個人情報保護管理者の設置、社内規程の整備、定期的な監査
2. **人的安全管理措置**: 従業員への教育研修、秘密保持契約の締結
3. **物理的安全管理措置**: 入退室管理、機器・電子媒体等の盗難等の防止
4. **技術的安全管理措置**: アクセス制御、不正アクセス対策、暗号化、ログ取得・分析

## 第10条 (情報漏洩時の対応)

万一、個人情報の漏洩、滅失または毀損が発生した場合、当社は以下の対応を行います。

1. 影響を受ける利用者への速やかな通知
2. 個人情報保護委員会への報告 (必要な場合)
3. 漏洩等の原因究明と再発防止策の実施
4. 必要に応じた被害拡大防止措置

## 第11条 (プライバシーポリシーの変更)

本ポリシーの内容は、法令の改正、本サービスの内容変更等に伴い、変更されることがあります。重要な変更については、本サービス上または利用者の登録メールアドレス宛にて通知します。

## 第12条 (お問い合わせ窓口)

本ポリシーに関するお問い合わせ、個人情報の開示等請求は以下の窓口までお願いします。

```
株式会社ルーキースマート
個人情報保護管理者: [氏名]
所在地: [本店所在地]
メール: privacy@[ドメイン]
```
