# AI Trend Column Rules

FDE AI/DX の AI Owned Media に毎日追加するコラムの運用ルール。

## Daily Rule

- 毎日 12:00 JST に、身近な AI トレンドニュースを 1 記事だけ選ぶ。
- 参照元リンクは 1 記事につき 1 本に絞る。
- ニュース公開日を必ず確認し、`newsPublishedAt` に `YYYY-MM-DD` で入れる。
- コラム追加日は `publishedAt` と `updatedAt` に入れる。
- 古いニュースでも生活者に近いテーマなら採用可。ただし、同じ質なら新しいニュースを優先する。

## Selection Rule

最優先する判断基準:

- 読者がすでに知っている製品・場面から入れること。
- `ChatGPT`、`Gemini`、`Google Home`、`Alexa`、`iPhone / Android`、`Google検索`、`Gmail`、`YouTube`、`LINE`、`Chrome`、スマート家電などを優先する。
- タイトルを読んだ時点で「自分の生活や仕事にどう関係するか」が分かること。
- 専門用語を主語にしない。`エージェントAI` やモデル名ではなく、買い物、検索、予定登録、家電操作、メール、資料作成など身近な行動を主語にする。
- 大きな業界ニュースより、明日から試せる機能追加・使い方・注意点を優先する。

優先ジャンル:

- `生活AI`: 買い物、検索、スマホ、ブラウザ、家事、旅行、教育など
- `セキュリティ`: 偽アプリ、拡張機能、詐欺、個人情報、ブラウザ権限など
- `仕事効率化`: メール、議事録、資料作成、CRM、問い合わせ対応など
- `AI雑学`: 人に話したくなる、使い方が想像しやすい AI ニュース

避けるテーマ:

- 研究者向けすぎるモデル性能比較
- 規制や投資だけで、生活や業務への接続が薄いニュース
- 参照元が不明確、日付が確認できない記事
- 既存記事と切り口がほぼ同じ記事
- 一般ユーザーが製品名や利用場面を想像できない抽象的な「AIの未来」記事
- `AI同僚`、`エージェント型` などの言葉だけで、具体的な使い方が見えない見出し

## Writing Rule

各記事は以下の構成にする。

- `title`: ChatGPT、スマホ、検索、家電など、入口になる身近な固有名詞または行動を入れ、変化が一発で分かるタイトルにする
- `description`: 何が変わるか、誰に関係あるかを 1 文で説明
- `lead`: 「3行で言うと」から始める
- `tips`: 4 点。生活者視点、企業視点、導入時の注意、FDE AI/DX への接続
- `sections`: 3〜4 セクション
  - まず、何が起きているのか
  - 生活または仕事ではどう変わるのか
  - 企業側の実務にどうつながるのか
  - FDE AI/DX の導線に置き換えると
- `sourceUrls`: 1 本のみ

## Thumbnail Rule

- 16:9 のサムネイルにする。
- ぱっと見でテーマが分かる大きな日本語テキストを入れる。
- テキストは 2 行までを基本にし、UI と重ならないようにする。
- 既存の dark / aurora / glass UI トーンに合わせる。
- ブランド名、実在企業ロゴ、読めない小文字、過剰な文字量は避ける。

## Implementation Rule

- 記事データは `apps/web/lib/ai-tips-columns.ts` に追加する。
- 画像は `apps/web/public/media/fde-ai-dx/` に保存する。
- LP の `AI OWNED MEDIA` カードは `AI Trend` の最新2記事を自動表示するため、カード本文を手作業で重複更新しない。
- `/columns` はジャンル別に見られる一覧として維持する。
- 型チェックを実行し、既存エラーと今回差分のエラーを分けて報告する。

## Skillization Note

このルールが 3 回以上安定して回ったら、以下を Codex skill 化する。

- 最新 AI ニュースの選定
- 参照元と公開日の確認
- コラムデータ作成
- サムネイル生成
- LP カード更新
- 型チェックと表示確認
