# ルーキースマートジャパン コーポレートサイト v1 仕様

## 目的

株式会社ルーキースマートジャパンの事業母体を伝える、日本向けの白・スカイブルー基調のコーポレートサイトとする。事業は「コーシキベース」「Go-to-Market設計」「マーケティング基盤設計」の3つ。ルキスマLABは後者2事業を束ねる法人向けサービスブランドとして扱う。

## 公開ページ

| URL | 役割 |
|---|---|
| `/` | コーポレートトップ |
| `/services` | 法人向けサービス総合案内 |
| `/services/gtm` | Go-to-Market設計 |
| `/services/marketing-infrastructure` | マーケティング基盤設計 |
| `/company` | 会社概要 |
| `/hiroki-sawasaka` | 代表ストーリー・経歴 |
| `https://koshikibase.jp` | コーシキベース公式サイト |

マーケティング用ドメインでは、`/lp`、`/services/rukisuma-lab`、`/media`以下、`/columns`以下を`/services`へ恒久転送する。`crm.rookiesmart-jp.com`は既存アプリとして分離し、変更しない。

## コンテンツと導線

- 初期版にはAIニュース、記事、採用、問い合わせフォーム、料金表を含めない。
- 商談導線は既存のGoogleカレンダー面談予約URLに統一する。
- コーシキベースの事業カードはカード全体を外部リンクとし、新しいタブで1クリック遷移する。
- GTM設計は市場理解からカスタマーサクセス、学習・改善までの7工程を表示する。
- マーケティング基盤設計は、オウンドメディア、計測、広告実験の3層で表示する。
- タグ管理は略称を使わず「Google Tag Manager」と表記する。
- バンディットは自動化や成果を保証せず、計測品質、最低母数、損失上限、探索枠、停止条件を定義した後に使う。

## 設計上の正本

公開インターフェースとなる事業カード、工程、成果物、実績指標、匿名リファレンスは`apps/web/lib/corporate-site.ts`の型付き設定を正本とする。ページ本文は各App Routerページを正本とする。

## 実績指標の公開ルール

- チーム数、リーグ数、都道府県数はコーシキベースのプロジェクトデータに基づく。
- 順位・サイト健全性は確認日と計測元を併記する。
- 公開直前にSearch ConsoleとSE Rankingを再取得する。
- 更新できない場合は順位数値を外し、構造・運用事例だけを掲載する。
- 検索順位、集客、商談、売上を保証する表現は使用しない。

## 公開前確認

1. 1440px、1280px、768px、390pxで全公開ページを確認し、必要に応じて320pxも確認する。
2. 横スクロール、カード高さ、図の文字切れ、ヘッダー、CTA、フッターを確認する。
3. 外部リンクの新規タブ、旧URL転送、Google Tag Manager表記、成果保証表現を確認する。
4. 氏名、医療情報、経歴、匿名リファレンスの公開文言を本人が最終確認する。
5. `type-check`、`lint`、`build`を通す。
6. ローカル確認後にVercelプレビューを作成し、明示承認後に本番公開する。
7. 既存Vercelデプロイはロールバック先として保持する。

## 未解決・公開直前に必要な確認

- コーシキベースの順位・健全性データの再取得
- 代表プロフィールの医療・経歴表現の最終承認
- 匿名リファレンスの要約表現の最終承認
- 会社所在地など会社情報の最新性確認

サイトとサービス構成の最終承認後に限り、結論、理由、未解決事項をObsidianの意思決定ログへ反映する。生データやビルドログはObsidianへ複製しない。
