## コンセプト

営業タイプ診断は、仕事中の行動特性をもとに、自分の営業スタイルを4つのキャラクターに分類する診断コンテンツ。

営業ドラゴン図鑑では、堅い性格診断ではなく「営業現場に出る癖」「失注しやすいパターン」「上司や組織との相性」をエンタメ化して見せる。

## 診断タイトル案

- 営業タイプ診断
- あなたの営業ドラゴン属性診断
- 営業スタイル4タイプ診断
- はぐれ博士の営業タイプ観測テスト

## リード文

仕事をしている時のあなたは、どんな営業タイプなのか。

以下の24項目の中から「仕事をしている時の自分はこんな感じだな」と思えるものにチェックを入れてください。点数をつける必要はありません。直感で選んで大丈夫です。

最もチェック数が多かったタイプが、あなたの主な営業スタイルです。ただし、人は誰でも複数タイプの要素を持っています。同点や僅差も問題ありません。

## 採点ロジック

各タイプに対応する番号のチェック数を数える。

| タイプ | 対応番号 |
| --- | --- |
| パイオニア | 1, 5, 9, 13, 17, 21 |
| インテグレーター | 2, 6, 10, 14, 18, 22 |
| ドライバー | 3, 7, 11, 15, 19, 23 |
| ガーディアン | 4, 8, 12, 16, 20, 24 |

最もチェック数が多いタイプを主タイプとする。複数タイプが同点の場合は、複合タイプとして扱う。

## 結果タイプ

### 1. パイオニア

別名: 開拓型 / 着火型 / 新規突破タイプ

パイオニアは、リスクを取ることを好み、集団に活力を与えるタイプ。直感に基づいて行動し、大胆で斬新なアイデアを好む。大きな成果を出すこともあれば、大きな失敗をすることもある。

営業での強み:

- 新規開拓に強い
- 初速が速い
- 未知の顧客や市場に飛び込める
- 相手の温度を上げるのが得意

失注しやすいパターン:

- 勢いで提案して、顧客の本音を拾いきれない
- クロージングが早すぎる
- 社内調整や事務処理を軽視する
- 勝ち筋が見えない案件にも突っ込む

モチベーションが上がるもの:

- 新しい挑戦
- 自発的な行動
- 裁量
- 大きな成果の可能性

モチベーションが下がるもの:

- 厳格なルール
- 他者からの否定
- プロセス重視
- 細かすぎる管理

はぐれ博士コメント:

> 火力はある。だが、商談はキャンプファイヤーではない。燃やす前に、相手が暖まりたいのか確認しろ。

### 2. インテグレーター

別名: 調和型 / 関係構築型 / 信頼醸成タイプ

インテグレーターは、他人との調和を重んじ、集団をまとめるのが得意なタイプ。人間関係を重視し、物事を白黒で判断しすぎず、人当たりが良い傾向がある。

営業での強み:

- 顧客との関係構築が得意
- 相手の不安や本音を拾える
- 社内外の調整がうまい
- 長期的な信頼を作れる

失注しやすいパターン:

- 嫌われたくなくて踏み込めない
- 決裁者や予算の話を避ける
- 相手の「検討します」を信じすぎる
- クロージングが弱くなる

モチベーションが上がるもの:

- コラボレーション
- 対人コミュニケーション
- 他人からの信頼
- 尊敬される関係性

モチベーションが下がるもの:

- 社内政治
- 対立
- 柔軟性のなさ
- 冷たい評価制度

はぐれ博士コメント:

> 優しさは武器だ。ただし、商談で優しすぎると、相手の先延ばしまで丁寧に包んでしまう。

### 3. ドライバー

別名: 達成型 / 目標突破型 / 数字狩りタイプ

ドライバーは、目標達成に向けて突き進むことを得意とするタイプ。論理的思考でデータを重視し、競争を楽しむ傾向がある。

営業での強み:

- 数字へのコミットが強い
- 商談を前に進める力がある
- データから勝ち筋を考えられる
- 意思決定が速い

失注しやすいパターン:

- 相手の感情や社内事情を軽視する
- 正論で詰めすぎる
- 受注確度を数字だけで見てしまう
- 顧客の温度感より進捗管理を優先する

モチベーションが上がるもの:

- 具体的なデータ
- 目標達成
- 効率的な意思決定
- 勝敗が明確な環境

モチベーションが下がるもの:

- 非効率なプロセス
- 感情的な議論
- 目標の不明確さ
- 曖昧な会議

はぐれ博士コメント:

> 数字を見る目は鋭い。だが、顧客はスプレッドシートではない。感情列が非表示になっているだけだ。

### 4. ガーディアン

別名: 守備型 / 安定運用型 / 精密管理タイプ

ガーディアンは、几帳面で、伝統や計画性を重んじるタイプ。ディテールを重視し、堅実に行動することで集団を支える。

営業での強み:

- 抜け漏れが少ない
- CRM入力や商談管理が丁寧
- 顧客対応が安定している
- 既存顧客や長期案件に強い

失注しやすいパターン:

- リスクを避けすぎてチャンスを逃す
- 変化が必要な局面で動きが遅れる
- 完璧に準備しようとして初動が遅い
- ルール外の顧客要望に弱い

モチベーションが上がるもの:

- 計画通りに進むこと
- 安定した環境
- 詳細な情報
- 明確な手順

モチベーションが下がるもの:

- リスク
- 変化
- 不確実性
- 場当たり的な方針転換

はぐれ博士コメント:

> 守りは強い。だが、営業の現場では、城壁の外に顧客がいることもある。

## 実装メモ

初期実装では、24問チェック式で十分。各チェックをタイプ別にカウントして、最大値のタイプを表示する。

同点時の扱い:

- 2タイプ同点: 複合タイプとして「主タイプ候補」を2つ表示する
- 3タイプ以上同点: 「バランス型」として、各タイプの傾向を一覧表示する
- 全部未選択: 「まだ観測不能」と表示し、再チェックを促す
