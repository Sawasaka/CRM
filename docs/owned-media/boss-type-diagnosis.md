## コンセプト

上司スタイル診断は、上司として仕事をしている時の行動特性をもとに、マネジメントの癖を4つのキャラクターに分類する診断コンテンツ。

営業ドラゴン図鑑では、堅いマネジメント診断ではなく「部下からどう見えているか」「成果が出る場面」「チームが詰まりやすいパターン」をエンタメ化して見せる。

## リード文

上司として仕事をしている時のあなたは、どんなタイプなのか。

以下の24項目の中から「上司として仕事をしている時の自分はこんな感じだな」と思えるものにチェックを入れてください。点数をつける必要はありません。直感で選んで大丈夫です。

最もチェック数が多かったタイプが、あなたの主な上司スタイルです。ただし、人は誰でも複数タイプの要素を持っています。同点や僅差も問題ありません。

## 採点ロジック

各タイプに対応する番号のチェック数を数える。

| 内部分類 | 対応番号 | 画面上のキャラ |
| --- | --- | --- |
| パイオニア型上司 | 1, 5, 9, 13, 17, 21 | 放任竜 フリーダム |
| インテグレーター型上司 | 2, 6, 10, 14, 18, 22 | 伴走竜 コーチャー |
| ドライバー型上司 | 3, 7, 11, 15, 19, 23 | 詰め竜 プレッシャー |
| ガーディアン型上司 | 4, 8, 12, 16, 20, 24 | 管理竜 キッチリ |

最もチェック数が多いタイプを主タイプとする。複数タイプが同点の場合は、複合タイプとして扱う。

## 結果タイプ

### 1. 放任竜 フリーダム

内部分類: パイオニア型上司

裁量と挑戦で現場を動かす、開拓型の上司。新しい挑戦や自発的な行動で部下の活力を引き出す。一方で、自由が放置に変わると新人や迷っている部下が孤立しやすい。

### 2. 伴走竜 コーチャー

内部分類: インテグレーター型上司

調和と信頼でチームをまとめる、関係構築型の上司。部下の本音や不安を引き出し、相談しやすい空気を作れる。一方で、対立を避けすぎると基準が曖昧になる。

### 3. 詰め竜 プレッシャー

内部分類: ドライバー型上司

目標とデータで現場を動かす、達成型の上司。数字へのコミットが強く、停滞した案件に緊張感を生む。一方で、正論で詰めすぎると部下が悪い情報を隠しやすくなる。

### 4. 管理竜 キッチリ

内部分類: ガーディアン型上司

計画と精度で組織を守る、安定運用型の上司。抜け漏れを防ぎ、再現性のある営業運用を作れる。一方で、変化や例外対応に遅れ、チャンスを逃すことがある。
