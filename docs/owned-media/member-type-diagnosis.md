## コンセプト

部下スタイル診断は、仕事中の行動特性をもとに、部下としての動き方・上司への求め方・チーム内で自然に担いやすい役割を4つのキャラクターに分類する診断コンテンツ。

上司タイプ診断と同じ4分類ロジックを使うが、画面上では「マネジメントする側」ではなく「任される側・成果を出す側」の文脈に変換する。

## リード文

仕事をしている時のあなたは、どんな部下タイプなのか。

以下の24項目の中から「仕事をしている時の自分はこんな感じだな」と思えるものにチェックを入れてください。点数をつける必要はありません。直感で選んで大丈夫です。

最もチェック数が多かったタイプが、あなたの主な部下スタイルです。ただし、人は誰でも複数タイプの要素を持っています。同点や僅差も問題ありません。

## 採点ロジック

各タイプに対応する番号のチェック数を数える。

| 内部分類 | 対応番号 | 画面上のキャラ |
| --- | --- | --- |
| パイオニア型部下 | 1, 5, 9, 13, 17, 21 | 自走竜 ランナー |
| インテグレーター型部下 | 2, 6, 10, 14, 18, 22 | 調整竜 ハーモニー |
| ドライバー型部下 | 3, 7, 11, 15, 19, 23 | 達成竜 アチーバー |
| ガーディアン型部下 | 4, 8, 12, 16, 20, 24 | 堅実竜 ステディ |

最もチェック数が多いタイプを主タイプとする。複数タイプが同点の場合は、複合タイプとして扱う。

## 結果タイプ

### 1. 自走竜 ランナー

内部分類: パイオニア型部下

仮説を持って自ら動く、開拓型の部下。新しいアイデアや挑戦機会に強く、裁量を渡すほど動きが速くなる。一方で、進捗共有が薄くなると上司が不安になりやすい。

### 2. 調整竜 ハーモニー

内部分類: インテグレーター型部下

周囲を見ながらチームを滑らかにする、調和型の部下。共感や調整に強く、チームの潤滑油になれる。一方で、対立を避けすぎると主張や決断が弱くなりやすい。

### 3. 達成竜 アチーバー

内部分類: ドライバー型部下

目標から逆算して成果を取りに行く、達成型の部下。数字やデータに強く、成果に直結する行動へ集中できる。一方で、効率や正しさを優先しすぎると周囲への共有が雑になりやすい。

### 4. 堅実竜 ステディ

内部分類: ガーディアン型部下

手順と正確さでチームを支える、守備型の部下。抜け漏れが少なく、安定した業務品質を作れる。一方で、曖昧な指示や急な変更には初動が遅れやすい。
