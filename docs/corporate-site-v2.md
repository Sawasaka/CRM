# ルーキースマートジャパン コーポレートサイト v2 仕様

## 目的

日本向けの白・スカイブルー基調のコーポレートサイトとして、次の3事業を明確に伝える。

1. コーシキベース
2. Go-to-Market設計
3. マーケティング基盤設計

ルキスマLABはGTM設計とマーケティング基盤設計を束ねる法人向けサービスブランドとする。

## 公開ルート

- `/`: コーポレートトップ
- `/services`: 法人向けサービス
- `/services/gtm`: GTM設計
- `/services/marketing-infrastructure`: マーケティング基盤設計
- `/company`: 会社概要
- `/hiroki-sawasaka`: 代表プロフィール
- `/legal`: 法務ドキュメント

`/lp`、`/services/rukisuma-lab`、マーケティングドメイン上の旧`/media`・`/columns`は`/services`へ転送する。CRMホストのアプリ機能とnoindex設定は維持する。

## デザイン

- 白70%、淡いスカイブルー20%、ネイビー8%、CTAブルー2%
- 日本語の見出しは明朝体、本文とUIはゴシック体
- 大きな余白、直線的な罫線、写真を中心とする日本企業向けの構成
- トップヒーローは野球、GTM、マーケティングの3枚を自動切替し、手動選択・停止・`prefers-reduced-motion`に対応
- Template Partyのコード・画像・CSS・JavaScriptは使用しない

## 公開インターフェース

事業、サービス工程、成果物、実績、匿名リファレンス、代表経歴、ヒーロー画像を`apps/web/lib/corporate-site.ts`の型付き設定に集約する。

外部リンクは`LinkTarget`の`kind: 'external'`で表し、`target="_blank"`と`rel="noopener noreferrer"`を付与する。コーシキベースはカード全体から直接外部遷移する。

## コンテンツ方針

- AIニュース、採用、料金表、汎用問い合わせフォーム、CMSはv2に含めない
- 商談CTAはGoogleカレンダーへ統一し、予約先は`https://calendar.app.google/gPiaQRbjMoBtnnKu8`とする
- GTMとGoogle Tag Managerを混同しない
- ベイズ・バンディットは成果保証として表現しない
- SEO実績は確認日・計測元を併記し、公開前に再確認できない値は掲載しない
- トップのコーシキベース事業カードは「SEO」と位置づけ、「公式情報を構造化した、中学硬式野球のデータベース型メディア。」と1行で説明する。3項目では、公式情報のデータベース設計、地域・カテゴリ別の検索意図に沿うページ設計、一次情報と独自のチームPRによって信頼性とオリジナリティを両立するSEO戦略を示す。オウンドメディア実績は1点だけ強調し、2026年8月9日のSE Rankingを根拠に「公開14日以内で、Google検索1位を5キーワード獲得」と表示する。補足は参照元と確認日に限定し、個別キーワードや検索ボリュームはカードへ掲載しない
- GTMカードは、番号・企業特徴・役職を同じ見出し行に置き、その下へ担当内容を簡潔な1行で添える。外資系企業の日本法人立ち上げにおけるSales Executive、正社員1人目として参画したプレシード期のITスタートアップの執行役員CRO、シード期のITスタートアップにおけるマーケティング統括責任者の3件を掲載する。会社名は掲載しない
- マーケティング基盤カードは数値実績に寄せ、約6カ月でARR 500万円、月間登録者50名超、オウンドメディアで検索1位5キーワードの3件を掲載する。説明文は掲載せず、検索順位は成果保証とは表現しない
- GTMカードでは実績下の支援項目とCTAを表示せず、カード全体をサービス詳細へのリンクとして扱う。マーケティング基盤カードは詳細ページへ遷移させず、「資料請求 →」から専用フォームを開く
- 資料請求フォームは会社名・氏名・メールアドレス・電話番号を必須とし、送信内容を`h.sawasaka@rookiesmart.jp`へ通知する。送信成功後に「ベイズ × バンディット戦略 意思決定フレームワーク」PDFをダウンロードし、Googleカレンダーの予約画面を開く
- GTMカードのタイトル直下には「市場・顧客を定義」「営業・マーケ・CSを接続」「90日実行計画を策定」を表示する。マーケティング基盤カードには「オウンドメディアを設計」「計測・CRMを接続」「広告実験ルールを設計」を表示し、英語のサブタイトルは使用しない
- 各カードの3件の実績は1つの白い実績パネル内へ3行で整理する。各行は青い番号、短い見出し、実績値で構成し、実績値だけを同じゴシック体、サイズ、太さ、数字組みへ統一する。実績ごとの大きな背景ボックスや大小差は使用しない
- リファレンスは匿名要約のみとし、推薦者名、会社名、原文、連絡先は掲載しない
