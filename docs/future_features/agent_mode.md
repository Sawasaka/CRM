# エージェントモード(Tool Use)— 将来仕様ドラフト

> **ステータス**: リリース後の追加機能として保留 (2026-05-05 凍結)
> **理由**: 初期リリースのコア機能集中・デバッグ工数の集中回避
> **再開判断**: 主要機能の安定運用 + dogfood 1ヶ月以上の知見蓄積後

---

## 背景・目的

ユーザーがチャット欄から自然言語で指示すると、AIが Front Office 内のCRM操作を自動実行する機能。

```
ユーザー: 「株式会社XXXを取引先に追加して、田中さんを担当者に紐付けて」
   ↓
AI が必要なツールを自動選択・実行
   ↓
書き込み操作は確認プレビュー → 承認後に実行
```

## 仕様確定事項

### スコープ
- ✅ **Front Office 内の Tool Use のみ** (関数呼び出し / Function Calling)
- ❌ **外部ブラウザ操作 (Codex+Browserbase) は対象外** (将来検討)

### 動作方針
| 項目 | 決定 |
|---|---|
| **承認フロー** | 書き込み・削除のみ承認モーダル / 読み取りは即時実行 |
| **対象プラン** | **PRO のみ** (Standardは非表示またはアップグレード誘導) |
| **失敗時** | AIが「分かりませんでした」ではなく、**ユーザーに質問する**(ヒアリング型) |
| **配置** | チャット入力欄の「全員」「モデル選択」の隣にトグル |
| **名称** | 仮: `⚡ エージェント` (要再検討) |

### 対応操作 (初期実装範囲)
- 企業 (Company) の作成 / 編集 / 削除
- コンタクト (Contact) の作成 / 編集
- 取引 (Deal) の作成 / ステージ変更
- パイプラインのフィルタ・並べ替え
- メール下書き作成
- 議事録の検索・要約
- (その他の業務機能はフェーズ分割で追加)

### クレジット消費レート (案)

| 操作種別 | 原価目安 | 消費 cr |
|---|---|---|
| 単純な読み取り(検索・要約) | 1-2円 | 3 cr |
| 単純な書き込み(コンタクト1件作成) | 2-3円 | 5 cr |
| 複合操作(複数項目を分析→入力) | 5-10円 | 15-30 cr |
| 議事録の長文要約 | 5-15円 | 20 cr |

PRO 2,000 cr/seat/月 想定 → 月 400-700 回操作可能。

---

## 検討した代替案 (採用しなかった)

### A. ブラウザ操作 (Codex + Browserbase)
- 試算原価: 6円(軽) / 30円(中) / 77円(重)
- メリット: 外部サービス連携(LinkedIn、HubSpot UI操作 等)が可能
- デメリット: 速度3-15分、信頼性70-80%、デバッグ困難
- **判断**: 将来オプション。Tool Use運用の知見が溜まってから検討。

### B. ハイブリッド (Tool Use + ブラウザ自動切替)
- メリット: 内部=高速 / 外部=フォールバックで両対応
- デメリット: 実装コスト大、エラー切り分けが難しい
- **判断**: 段階的導入。まず Tool Use のみ。

## 実装フェーズ案 (再開時の参照用)

```
Phase 1 (1週)  基盤
  - ツール定義(createCompany, updateContact, ...)
  - GPT-4o function calling 接続
  - チャット欄トグル + プラン制限UI

Phase 2 (1-2週)  CRUDコア
  - 企業 / コンタクト / 取引 のCRUD ツール
  - 確認モーダル(書き込み・削除)

Phase 3 (1-2週)  高度な操作
  - パイプラインフィルタ
  - メール下書き作成
  - 議事録検索・要約
  - 不明時のAIヒアリング(再質問フロー)

Phase 4 (1週)  仕上げ
  - クレジット消費実装(消費レート反映)
  - エラーハンドリング・トースト
  - PROアップグレード動線
```

合計: **4-6週間** (1人想定)

## 法務・契約上の留意点 (再開時に参照)

- **OpenAI ToS**: 「下流ユーザーへの再販」は基本OKだが、自社サービスとして提供する建付けが推奨(顧客にAPI生アクセスは別ルール)
- **個人情報**: 顧客が個人情報を含む指示をした場合、OpenAI規約上は処理可だが、プライバシーポリシーで明示必要
- **クレジット消費の透明性**: 利用規約の第6条(クレジット)に「Tool Use 操作の消費レートは別途定める」を追記すべき
